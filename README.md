# HASHING-SIMULATOR
A Hashing Simulator developed as a Final Project in Discrete Structures 2 during our second year in college.
This website is a simple data structures and algorithms simulator where users can input up to 10 numbers into an array with a size limit of 15. It supports storing, searching, and visualization of how data is placed using hashing. It also includes linear and binary search, as well as basic linear and quadratic operations, allowing users to see how values are stored and located step by step.
